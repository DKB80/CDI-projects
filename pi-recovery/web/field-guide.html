CDI Recovery — Field Guide

Offline reference. Use only on equipment you own or are contracted to service.

Reach this Pi

  • On a network: ssh pi@cdi-recovery.local, or this panel at http://cdi-recovery.local:5000.
  • No site network: on the Pi run sudo cdi-field-mode.sh on 15, join WiFi CDI-Recovery (passphrase from your CDI credentials), then browse http://192.168.4.1:5000. It reverts to normal WiFi automatically.
  • Remotely: the office can reach it over Tailscale.

WIN Windows — reset a lost local password

  1. Plug the Pi's USB/OTG port into the PC. Arm the drive: sudo cdi-gadget-massstorage.sh on.
  2. Power on the PC, open the boot menu (F12/F2/Esc), pick the USB drive.
  3. SystemRescue loads. lsblk to find the Windows disk, then ntfs-3g /dev/sdXn /mnt.
  4. cd /mnt/Windows/System32/config → chntpw -u "Administrator" SAM → choose (1) clear password, save.
  5. Shut down, then sudo cdi-gadget-massstorage.sh off. Log in with a blank password.
⚠ BitLocker: if the drive is encrypted you need the recovery key first, or it can't be read.

MAC Mac (Intel) — reset a lost password

No boot image needed — use the Mac's built-in Recovery.
  1. Shut down. Power on and hold ⌘ + R until the Apple logo/spinner appears.
  2. Menu bar: Utilities → Terminal.
  3. Type resetpassword, Return. Pick the user, set a new password, save, restart.
FileVault on? You may need the disk password or recovery key first. Then install Tailscale from the panel's Hosted installers.

STOP Mac (Apple Silicon M1/M2/M3)

Different path — don't force our USB, it won't boot.
  1. Confirm chip: Apple menu → About This Mac. Apple M1/M2/M3 → use this path.
  2. Shut down. Hold the power button until "Loading startup options" → Options → Continue.
  3. Utilities → Terminal → resetpassword, or "I forgot my password".
  4. No password AND no recovery key with FileVault on = unrecoverable by design → escalate to the office.

CFG Standardise / verify a machine

  • Networked: on this Pi, cd /opt/cdi-recovery/config/ansible → ansible-playbook site.yml --check --diff (preview) → without --check to apply. Windows needs bootstrap-winrm.ps1 run once per host first.
  • Standalone: from the Pi's USB, elevated: configure.ps1 -WhatIf (preview) → configure.ps1 → verify.ps1 (Mac: sudo bash configure.sh). Each run writes a *.report.txt — keep it as the compliance record.
