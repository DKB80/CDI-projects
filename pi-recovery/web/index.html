Guided recovery

WIN Windows — reset a lost local password
  1. Plug the Pi's USB/OTG port into the PC, then arm the drive: sudo cdi-gadget-massstorage.sh on.
  2. Power on the PC and open its boot menu (usually F12, F2 or Esc) → choose the USB drive.
  3. SystemRescue loads. Find the Windows disk with lsblk, then mount it: ntfs-3g /dev/sdXn /mnt.
  4. cd /mnt/Windows/System32/config then chntpw -u "Administrator" SAM → pick (1) clear password, save.
  5. Shut down. On the Pi: sudo cdi-gadget-massstorage.sh off. Log in with a blank password.
⚠ If the drive is BitLocker-encrypted you need the recovery key first, or it can't be read.
MAC Mac (Intel) — reset a lost password
No boot image needed — use the Mac's built-in Recovery.
  1. Shut the Mac down. Power on and immediately hold ⌘ + R until the Apple logo / spinner appears.
  2. At the macOS Utilities screen, open the menu bar: Utilities → Terminal.
  3. Type resetpassword and press Return — the Reset Password tool opens.
  4. Pick the user, set a new password, save, then restart.
If FileVault is on you may need the disk password or recovery key first. Once back in, install Tailscale from Hosted installers below.
STOP Mac (Apple Silicon M1/M2/M3) — different path
Apple Silicon Macs don't use ⌘-R and won't boot our USB. Don't force it.
  1. Confirm the chip: Apple menu → About This Mac. If it says Apple M1/M2/M3, use this path.
  2. Shut down. Press and hold the power button until "Loading startup options" → Options → Continue.
  3. Utilities → Terminal → resetpassword, or use "I forgot my password" / Recovery Assistant.
  4. No password and no recovery key with FileVault on = data is unrecoverable by design — escalate to the office.
